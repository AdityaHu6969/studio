# **App Name**: Patel College Hub

## Core Features:

- User Role Selection: Allows users to select their role (Student, Teacher, Admin) upon login.
- Login & Onboarding: Manages user login, email/mobile verification via OTP, and password setup.
- Tiered Admin Roles: Implements God Admin and Admin roles with distinct permissions for user and data management.
- Attendance Marking (Teachers): Enables teachers to mark student attendance efficiently.
- Attendance Dashboard (Students): Provides students with a visual dashboard with Pie Charts and Bar Graphs for attendance tracking.
- Security Lock & PIN Unlock (Admins): Adds an extra layer of security for Admin accounts.
- PWA Installation: Makes the website installable as a Progressive Web App on desktop and mobile devices.

## Style Guidelines:

- Primary color: Indigo (#4B0082), symbolizing knowledge and trustworthiness. It provides a professional and calming feel.
- Background color: Light lavender (#E6E6FA), a soft and desaturated hue from the indigo family, creating a subtle and uncluttered background.
- Accent color: Violet (#8F00FF), analogous to indigo, offers a vibrant highlight for interactive elements without overwhelming the primary aesthetic.
- Body and headline font: 'Inter', a grotesque sans-serif, providing a modern and neutral appearance suitable for both headlines and body text.
- Consistent use of flat, line-art style icons representing various aspects of college life such as academics, attendance, and user roles.
- A responsive, grid-based layout that adapts to various screen sizes, ensuring flawless UI on all devices. Optimize for speed and responsiveness using techniques like lazy loading, and efficient CSS.
- Subtle transition animations for page loads and user interactions, enhancing user experience without being distracting. Ensure animations are performant and do not negatively impact page load times.
